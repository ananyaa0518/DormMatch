# DormMatch

ML-based hostel roommate recommendation system exploring lifestyle compatibility through data cleaning, EDA, feature engineering, clustering, similarity-based recommendations, and evaluation.


## Project Structure
- `data/raw/`: original dataset
- `data/processed/`: cleaned/intermediate data
- `data/final/`: model-ready datasets
- `notebooks/`: step-by-step analysis notebooks
- `src/`: reusable Python modules
- `app/`: Streamlit application
- `reports/`: analysis findings and figures

## Workflow
1. Data inspection
2. Data cleaning
3. Exploratory data analysis
4. Feature engineering
5. Lifestyle clustering
6. Recommendation system
7. Evaluation
8. Dashboard
